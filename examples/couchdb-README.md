Copy `couchdb_example.bui` or `couchdb_attachments.bui` into a fresh directory with `packages/couchdb-0.3.0.buipkg`, then compile with `buoy`. Keep the package present: it supplies system libcurl link stubs. Linux requires libcurl.so.4. Configure COUCHDB_URL, COUCHDB_USERNAME, COUCHDB_PASSWORD and COUCHDB_DATABASE for a disposable database. Use HTTPS for remote credentials.
